Pricing assumptions:
- Currency conversion used for this estimate: 1 USD = 150 ETB.
- Prices are agency-grade custom software estimates for a NestJS, Next.js, Prisma, PostgreSQL system.
- Ranges include feature analysis, backend API, database modeling, frontend UI, validation, role checks, audit behavior where applicable, and implementation testing.

1. Core Auth & Role-Based Access Control with Audit Logs
Technical Description:
Staff authenticate with email and password using bcrypt password hashing and JWT access tokens. The system enforces the three internal roles: SUPER_ADMIN, CASE_WORKER, and VIEWER through backend guards, decorators, protected routes, session handling, forced password-change workflow, and global audit logging for login and data actions.
Operational Value:
This protects vulnerable beneficiary data and ensures only authorized FENAID staff can view or modify records. The audit trail gives management a tamper-resistant accountability record for staff actions, role changes, record edits, and sensitive operations.
Estimated Price Allocation:

Recommended negotiation strategy:
1. Keep the system foundation, Auth/RBAC, Parent Registry, Child Registry, and Audit Logs as non-removable baseline modules. Removing these weakens security, data integrity, and the basic case-management workflow.
2. Treat Advanced Data Query, Dashboard/Reports, Notifications, Documents, Bilingual Localization, and Fund/Donations as menu items that can be phased if budget is constrained.
3. If the client removes a feature, reduce both price and timeline only when the feature is truly independent. Do not remove shared backend, database, role, audit, or dashboard foundation work from the baseline.
4. If the client adds new requirements, price them as change requests with a written scope, acceptance criteria, and separate estimate before implementation.
5. For contract clarity, convert the final selected menu into milestones: Foundation, Core Registry, Service Delivery, Reporting/Research, Automation/Polish, and Deployment.
